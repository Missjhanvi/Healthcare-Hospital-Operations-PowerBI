# GitHub Publication & Privacy Checklist

- [ ] Add your name and links to README and portfolio copy.
- [ ] Check that screenshots do not show names or patient identifiers.
- [ ] **Do not upload the source workbook** containing patient names and IDs unless independently cleared for release.
- [ ] **Do not upload the original PBIX**: the embedded data model can contain patient-level records even if report visuals look aggregated.
- [ ] If publishing an interactive report, create and independently review a sanitized model/report first; public publishing may reveal underlying data.
- [ ] Inspect the provided department-level summary for low-count privacy disclosure issues under your applicable policy.
- [ ] Create a new public GitHub repository (suggested: `healthcare-operations-revenue-powerbi`).
- [ ] Extract this ZIP and upload its folder contents to the repository root (not the enclosing folder).
- [ ] Add a GitHub About description, website and topics.
- [ ] Pin the repository and link it from your portfolio.
- [ ] Attach a sanitized PBIX only if it has undergone a full privacy review; otherwise link to the documented case study and presentation.
