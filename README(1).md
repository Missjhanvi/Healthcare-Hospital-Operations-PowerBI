# Healthcare Hospital Operations and Revenue Dashboard

## Project Overview

This Power BI project analyzes hospital operations, service quality, patient follow-up workload, and revenue performance.

The dashboard helps identify operational delays, patient-service issues, provider performance patterns, and financial risks across hospital departments.

## Project Summary

- Tool: Microsoft Power BI
- Report pages: 6
- Visuals: 59
- Model tables: 5
- Named measures: 25
- Main areas: encounters, wait time, cancellations, no-shows, patient satisfaction, follow-ups, billed revenue, approved revenue, collected revenue, pending payments, and denied claims

## Dashboard Pages

### 1. Hospital Operation Overview

Provides an executive overview of:

- Total encounters

- Average wait time
- Department performance

### 2. Hospital Operation – Quality and Follow-Up

Analyzes:

### 3. Hospital Operation – Performance

Analyzes:

- Completion rate
- No-show rate

- Facility-level volume
- Billed revenue
- Pending revenue

### 4. Revenue Overview

Provides an overview of:

- Total billed amount
- Total approved amount
- Total collected amount
- Total pending amount
- Total denied amount
- Payer performance
- Denial reasons

### 5. Revenue Analysis

Analyzes financial risk by:

- Department
- Appointment status
- Facility
- Follow-up workload

### 6. Operational and Financial Connection

Connects operational outcomes with financial performance, including:

- Completed appointments and revenue
- No-shows and lost revenue opportunities
- Cancelled encounters and pending amounts
- Department performance and approved claims
- Operational workload and denied claims

## Business Questions Answered

1. How many encounters were completed, cancelled, missed, or rescheduled?
2. Which departments have the highest patient volume?
3. Which departments have the longest average wait times?
4. Where are cancellations and no-shows creating operational risk?
5. Which diagnosis categories require the most follow-up?
6. How are providers performing based on activity and patient satisfaction?
7. How much revenue was billed, approved, collected, pending, or denied?
8. Which payer types and denial reasons create the greatest financial risk?
9. How do hospital operations affect financial performance?

## Key Insights

- Departments can be compared using patient volume, wait time, completion rate, cancellation rate, and no-show rate.
- Follow-up analysis helps identify high-risk diagnosis categories and patient groups.
- Provider-level analysis supports the evaluation of workload, visit duration, and patient satisfaction.
- Revenue analysis highlights billed, approved, collected, pending, and denied amounts.
- Payer and denial analysis helps identify areas with possible reimbursement risk.
- Operational and financial measures show how patient-service outcomes may influence hospital revenue.

## How to View the Dashboard

1. Download the Power BI project file.
2. Open the file using Microsoft Power BI Desktop.
3. Navigate through all six report pages.
4. Use the available slicers to filter the dashboard by department, facility, encounter date, payer type, provider, and other categories.
